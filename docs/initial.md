Я хочу написать утилиту, которая будет позволять объяснить что-либо (например, выделен какой-то текст, нужно объяснить
подробнее, что это. И в дальнейшем продолжить задавать по этой теме вопросы ИИ в чате).
Как дополнительные функции:
- можно быстро перевести выделенный текст
- можно сделать выжимку из длинного текста или файла
- можно попросить объяснить, что нарисовано на картинке (картинка может быть в буфере обмена, либо это может быть путь
  к картинке)
- можно добавить свои промпты

Цель: уменьшить количество телодвижений, чтобы пользователю было удобно вызвать нужную функцию.
Например, по назначенному шорткату показывать окно с подходящими функциями, пользователь нажимает на нужную функцию,
после чего она вызывается (например, переводит текст. В дальнейшем в окне с переводом можно продолжить диалог с ЛЛМ
по этому контексту). Можно отдельным функциям назначить отдельный шорткат.

В настройках можно настроить API для LLM (например, DeepSeek, OpenRouter, OpenAI, Custom OpenAI-compatible).
Должна быть как минимум 1 ллм по умолчанию, и можно добавить дополнительные. Например, для большинства функций
хватит deepseek flash, для распознавания картинок надо выбрать настроенную модель, которая поддерживает работу
с картинками (например, ллм с моделью deepseek-v4-flash-vision-exp, либо вообще модель OpenAI)

Приложение должно быть разработано с учётом i18n. По умолчанию берётся язык ОС. Если язык не поддерживается приложением,
используется английский. Язык можно сменить в настройках.

В исходниках все комментарии и документация, которая коммитится в git, должна быть на английском языке.

Приложение должно собираться для: MacOS, Windows, Linux.
При этом разработку должны мы уметь вести как в MacOS, так и в Windows.

При сборке на MacOS сборку для Windows можно тестировать на VMWare Fusion.
